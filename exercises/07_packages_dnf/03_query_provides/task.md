# DNF: finding and installing the right package

A teammate wants to use the `killall` command on this box to kill processes by
name, but it isn't there. `killall` isn't a package name of its own -- it
ships as part of something else.

**Task:**

1. Figure out which package provides the `killall` command.
2. Install that package.
3. Confirm `killall` is now available.
