# Essentials: navigating the filesystem and reading docs

Before anything else on the exam, you need to move around the filesystem fast
and know how to look up a command you half-remember instead of guessing.

**Task:**

1. Create the nested directory path `/root/rhelings-lab/archive/2026/reports`
   in a **single command**. If you're not sure how to make `mkdir` create all
   the missing parent directories at once instead of erroring out, check
   `man mkdir` or `mkdir --help` for the option that does it.
2. Inside that deepest directory, create an empty file named `q3.txt`.

Nothing here is more complex than that -- the point is muscle memory for
`man`/`--help` and one flag you'll use constantly (`mkdir -p`), not cleverness.
